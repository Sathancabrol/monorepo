# GAME DESIGN — Synthèse V0.1

## Vision

Supernatural: Outsider est un jeu solo systémique dans l'univers de Supernatural où le joueur ne commence pas comme chasseur. Il vit une vie entière : naissance/adoption → enfance → adolescence → études/jeune adulte → escalade surnaturelle → conflit cosmologique → mort → audit → réincarnation → NG+.

Le jeu doit donner l'impression d'une vie persistante dans un monde qui continue sans le joueur.

## Boucle fondamentale

INFORMATION → PRÉPARATION → ACTION → EXPÉRIENCE → RÉPUTATION → CROYANCE → POUVOIR

Une capacité doit créer une possibilité de gameplay, pas seulement ajouter un bonus numérique.

## Structure d'une situation

SITUATION → OBJECTIF → CONTRAINTE → TEMPS → ENVIRONNEMENT → PNJ → INFORMATION → ACTIONS → CONSÉQUENCES → TRACE

## Létal / non-létal

Le système n'est pas une morale binaire.

Échelle générale :
AVOID → OBSERVE → DIALOGUE → DECEIVE → DISTRACT → BYPASS → IMMOBILIZE → KNOCK OUT → CAPTURE → COERCE → EXORCISE/BANISH → INJURE → KILL

Pour le surnaturel :
KILL / CAPTURE / EXORCISE / BANISH / SEAL / PACT / HELP / LET GO / TRANSFORM

Chaque solution doit modifier les informations disponibles, les témoins, les relations, les factions, la police, la réputation et le monde.

## Carré d’As

Application du téléphone et interface de connaissance.

Il contient : carte, contacts, messages, recherche, dossiers, indices, personnes, lieux, créatures, quêtes, choix, inventaire, état, réputation, preuves et graphe de connaissance.

Il n'est jamais omniscient.

États de connaissance :
- connu ;
- suspecté ;
- possible ;
- inconnu ;
- expérimenté ;
- souvenir d'une vie précédente.

## Monde

Monde ouvert mais segmenté en régions/districts afin de permettre des niveaux fortement travaillés.

Le monde évolue sans le joueur.

Un événement peut arriver parce que le joueur intervient, mais aussi parce qu'il ne fait rien.

## Perks

Domaines : physique, mental, technologie, combat, reconnaissance, conduite, investigation, science, ingénierie, médecine, chimie, architecture, histoire, langues, survie, occultisme, alchimie.

Exemple : Diagnostic ne donne pas simplement +10 %. Il révèle une anomalie mécanique et ajoute une action possible.

## Cosmologie

L'Outsider est lié à une anomalie cosmologique : accumulation de « déchets » du Vide / variations causales dans une autre branche, qui agit comme signal attirant une intervention cosmique.

Le Plombier est un concept mystérieux de réparation cosmique.

Death connaît davantage que les autres. Amara comprend progressivement. Chuck n'est pas simplement un méchant.

Le Void reste le boss final. Le joueur le repousse ; le Void retourne dormir. Chaque vie se termine par la mort du joueur.

## NG+

Le NG+ conserve une partie des traces de vies précédentes et ajoute surtout de la connaissance : reconnaissance de lieux, événements, causalités, opportunités et interprétations alternatives.

Après plusieurs boucles, une même entité peut prendre des rôles contradictoires selon les choix.

## Vertical slice

Zone : maison + village + forêt.
Temps : une journée + une nuit.
NPC : 10–20 simulés.
1 créature.
1 enquête complète.
1 base.
1 téléphone + PC.
1 arme de mêlée + 1 arme à feu + CQC.
2–3 relations.
1 incident police.
1 faction.
1 mini-écosystème miasma.
1 événement caché.
1 boucle mort/audit/NG+.

## Non-négociables

1. Le monde continue sans le joueur.
2. Le joueur peut être dans l'erreur.
3. Les PNJ peuvent être dans l'erreur.
4. Les organisations peuvent être dans l'erreur.
5. Toute information a une provenance.
6. Une capacité crée une possibilité.
7. Une action importante laisse une trace.
8. Létal ≠ mauvais automatiquement.
9. Non-létal ≠ meilleur automatiquement.
10. Les quêtes acceptent plusieurs solutions.
11. Les conséquences peuvent être différées.
12. Carré d’As n'est jamais omniscient.
13. Le hasard est contraint par le contexte.
14. Les lieux réels servent le gameplay.
15. Les monstres ont une écologie.
16. La progression modifie les possibilités.
17. NG+ ajoute de la connaissance.
18. Les secrets cosmiques sont progressifs.
19. RAW jamais supprimée.
20. Chaque prototype teste une hypothèse précise.
