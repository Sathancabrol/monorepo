# Préfixes acceptés : glob: (le * traverse les /)  ·  regex:  ·  path: (chemin exact)  ·  chemin nu
# `#` en début de ligne = commentaire. Seules les lignes ACTIVES sont retirées de l'historique.

# ── Zone A — données personnelles de tiers (à garder active) ──────────────────────────────
#   56 documents + images sous projects/proto-cognitorium/raw : CV de personnes, questionnaires,
#   devis, rapports de stage, mémoires. C'est la zone la plus sensible.

#   plannings, comptes-rendus, grilles de salaires, guides FNTP/SEQUELEC…
