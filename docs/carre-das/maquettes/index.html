🃏 Carré d'As — trois interfaces à comparer

Chaque maquette est une page HTML autonome (aucune dépendance, rien à installer) : clique pour l'ouvrir dans ton navigateur. Les trois partagent le même fond, le même rail, la même barre d'état et la même palette Ctrl+K. Elles diffèrent par ce qui est au centre.

V1 — Le Carré accueil

La simplicité assumée
  • Quatre portes : Projets · Carte · Documents · Agents
  • Reprises, activité, à traiter — rien d'autre
  • Compréhensible en 5 secondes, clavier d'abord
  • Idéal : nouvel utilisateur, association, mairie
Ouvrir V1

V2 — L'Atelier travail

Le poste de travail métier
  • Le projet est le conteneur (chantier Barbazan)
  • Onglets : Documents · Prix · Métrés · Planning · Carte · 3D…
  • Panneau détails + provenance, dock d'outils, journal
  • Idéal : usage quotidien, 154 documents, module BTP
Ouvrir V2

V3 — L'Arbre exploration

La carte cognitive
  • Arbre de compétences + axe de vie + fiche liée
  • Chaque nœud : statut, preuves, disponibilité estimée
  • Zoom sémantique, 5 représentations interchangeables
  • Contient un mode liste équivalent (accessibilité)
Ouvrir V3
Ma recommandation : V1 comme accueil par défaut + V2 comme espace de travail + V3 comme module d'exploration.
Pourquoi : ton cahier des charges impose « simplicité en surface, profondeur à la demande » (UX-01), deux densités d'information (UX-07) et « le graphe n'est pas l'unique porte d'entrée » (UX-10). Cette combinaison est aussi la seule qui reste fluide sur une GTX 1060 6 Go.
