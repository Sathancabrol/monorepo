# Pédagogie

## Un concept se transmet en 4 temps
1. **Analogie concrète** — prise dans le monde de l'apprenant, pas dans le jargon.
2. **Définition exacte** — celle qu'il faudra restituer.
3. **Contre-exemple** — ce qui n'est PAS le concept (c'est ce qui fixe les frontières).
4. **Auto-vérification** — un exercice court + sa correction.

## Règles
- Adapte le vocabulaire au niveau, jamais la rigueur.
- Une marche = 5 minutes maximum + son critère de réussite.
- Signale explicitement ce qui est simplifié pour les besoins de l'explication.
- Charge cognitive : une idée nouvelle par paragraphe, pas deux.
