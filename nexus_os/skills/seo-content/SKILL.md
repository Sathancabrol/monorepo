# Contenu SEO

1. Intention d'abord : informationnelle, comparative ou transactionnelle — le format en découle.
2. Un mot-clé principal, 3-4 secondaires ; jamais de bourrage.
3. Titre ≤ 60 caractères, meta description ≤ 155, promesse explicite.
4. H2 = les questions réelles posées ; réponse dans les 2 premières lignes sous chaque H2.
5. Premier paragraphe autonome : il doit pouvoir devenir un snippet.
6. Maillage : 2 liens internes contextuels, texte d'ancrage descriptif.
7. Signale toujours ce qui nécessiterait une donnée réelle (volume, difficulté) au lieu de l'inventer.
