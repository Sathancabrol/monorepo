# Mémoriser & améliorer

## Avant la tâche
`memory_recall` sur les mots-clés du sujet : réutilise plutôt que redécouvrir.

## Après la tâche
Enregistre au plus 3 items, dans la bonne catégorie :
- **fact** — vérifié, réutilisable tel quel (« le build se lance avec X »).
- **decision** — choix + justification + date.
- **lesson** — ce qui a échoué et pourquoi, formulé pour être reconnu la fois suivante.

## Règles
1. Une leçon utile commence par le déclencheur : « Quand X, ne pas Y, parce que Z ».
2. Pas de mémoire pour ce qui se relit dans le code.
3. Un souvenir contredit se corrige, il ne s'empile pas.
