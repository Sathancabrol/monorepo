BONE — ZIP d'installation Windows
=================================

1. Extraire TOUT le zip dans un dossier (clic droit → Extraire).
2. Double-clic sur  INSTALLER.bat
   (si Windows bloque : Plus d'infos → Exécuter quand même)
3. L'installeur :
     - pose Python s'il manque (ou t'envoie sur python.org)
     - installe Bone dans  %LOCALAPPDATA%\Bone
     - te demande le TOKEN du bot Discord (une fois)
     - OUVRE Discord pour que tu CHOISISSES le serveur
     - lance Bone

Ensuite Bone est en ligne sur le serveur que tu as coché.
Raccourci Bureau : "Bone". Laisse le PC allumé, ou accepte
"lancer au démarrage de Windows".

Créer le bot Discord (l'installeur t'ouvre la page) :
  https://discord.com/developers/applications
  New Application → Bone
  Bot → Add Bot
  MESSAGE CONTENT INTENT = ON
  Reset Token → copier

Après install — plus de droits / connexions
-------------------------------------------
Dans Discord :  /autorisations
  → boutons : modération, vocal, salons, admin
  → Discord s'ouvre, tu re-choisis le serveur, Autoriser.

Sur le PC : menu Démarrer → Bone — autorisations
  1 Droits Discord
  2 Intents (membres, présence) — portail Bot
  3 Connexions (OpenAI / Groq / Ollama) dans .env

Ou à la main : Discord → Paramètres du serveur → Rôles → Bone.

Désinstaller : %LOCALAPPDATA%\Bone\desinstaller.bat
