# RAW 46 — Économie et société surnaturelle

> Règle fondatrice du chantier OUTSIDER · statut : **ACTIVE** · source : discussion game design du 08/10/2026
> ⚠️ Cette règle corrige une dérive antérieure : il ne faut **pas** inventer artificiellement une « société des monstres » façon RPG fantasy.

## 1. L'énoncé
**Le marché noir des monstres existe déjà dans la série.** Des humains et des monstres peuvent collaborer ou appartenir à une même organisation. Des objets surnaturels peuvent être vendus, échangés ou recherchés. **Le jeu doit exploiter ces éléments existants plutôt que créer artificiellement une société fantastique sans rapport avec Supernatural.**

## 2. Conséquence game design
Le monde surnaturel fonctionne comme une **couche cachée de la société humaine** :

```
                    SOCIÉTÉ
                       │
          ┌────────────┴────────────┐
          │                         │
       HUMAIN                    SURNATUREL
          │                         │
   entreprises                monstres
   police                     sorciers
   commerces                  démons
   criminalité                vampires
   politique                  fantômes
          │                         │
          └──────────┬──────────────┘
                     │
              RÉSEAUX MIXTES
                     │
       ┌─────────────┼─────────────┐
       │             │             │
    MARCHÉ        SERVICES       TRAFICS
    NOIR          OCCULTES       D'OBJETS
```

## 3. Les monstres sont des acteurs économiques
- **Un vampire** peut : acheter un objet · vendre du sang · employer des humains · posséder un commerce · financer une activité · avoir une dette · être membre d'une organisation · travailler avec une sorcière · trahir son partenaire.
- **Une sorcière** peut : vendre des enchantements · acheter des composants · pratiquer pour des clients humains · travailler avec des créatures · avoir plusieurs identités · posséder une maison parfaitement normale.
- **Un humain** peut : connaître le surnaturel · commercer avec des monstres · chasser des monstres · exploiter des artefacts · travailler pour une organisation mixte.

## 4. Ne pas tout transformer en quête
La découverte est **accidentelle et optionnelle** :

```
JOUEUR SE PROMÈNE → ENTRE DANS UN BAR → ENTEND « La livraison arrive demain. »
→ OBSERVATION → INDICE → SAC / SYMBOLE / NOM → CARRÉ D'AS (recherche)
→ « Ce symbole est associé à... » → découverte du réseau surnaturel
```
**Ou il peut ne rien faire. Et la livraison aura quand même lieu.**

## 5. Progression par la connaissance (NG+)
Le joueur expérimenté reconnaît les structures et **saute des étapes** :
```
PREMIÈRE VIE : « C'est quoi ce truc ? »
   ↓ EXPÉRIENCE
NG+   : « Je connais ce symbole. »
   ↓ EXPÉRIENCE
NG++  : « Je sais qui vend ce type d'objet. »
   ↓ EXPÉRIENCE
NG+++ : « Je sais pourquoi ils le vendent. »
```

## 6. Règle générale dérivée
> **Tout ce qui existe dans le canon et qui peut être systématisé doit devenir potentiellement systémique.**

Le Game Design doit donc contenir une couche **SOCIÉTÉ SURNATURELLE CACHÉE** avec notamment : marchés noirs · trafics · objets surnaturels · services occultes · organisations · chasseurs · humains informés · humains ignorants · monstres intégrés à la société · alliances humain/monstre · conflits entre créatures · territoires · dettes · contrats · commerce · informations · réseaux clandestins.

**Et pas besoin que le joueur rencontre tout dans l'histoire principale** : une grande partie doit exister dans le World Simulation, prête à produire des rencontres, enquêtes, quêtes et ramifications émergentes.
